# 🚀 RAM Optimizer (AutoHotkey v2)

Windows sisteminizdeki gereksiz bellek kullanımını temizleyen ve sistem performansını artıran hafif, taşınabilir ve açık kaynaklı bir araç.

A lightweight, portable, and open-source tool designed to clear unnecessary memory usage and boost system performance on Windows.

## ✨ Özellikler / Features

* **Real-time Monitoring:** Anlık RAM kullanımı takibi ve görsel ilerleme çubuğu. 
* **One-Click Optimization:** Tek tıkla çalışan tüm işlemlerin bellek setlerini (`EmptyWorkingSet`) temizleme. 
* **Auto-Optimize:** Belirlenen aralıklarla (30 dakika) otomatik temizlik modu. 
* **Modern UI:** Karanlık (Dark) ve Aydınlık (Light) tema desteği. 
* **Mini Mode:** Sadece istatistikleri gösteren, yer kaplamayan minimal arayüz. 
* **Smart Indicators:** Doluluk oranına göre renk değiştiren (Yeşil/Sarı/Kırmızı) gösterge. 
* **Always on Top:** Pencereyi her zaman üstte tutma seçeneği.

## ⚙️ Kurulum / Installation

1.  **AutoHotkey v2** yüklü olduğundan emin olun.
2.  `RamOptimizer.ahk` dosyasını indirin.
3.  Dosyaya sağ tıklayıp **Run Script** deyin veya `.exe` haline getirerek kullanın.

> **Not:** Uygulama, tüm işlemlerin belleğini temizleyebilmek için yönetici izinleri (Admin) isteyecektir. 

---

## 🛠️ Kullanım / Usage

* **Sürükle-Bırak:** Arayüzün herhangi bir yerinden tutarak pencereyi taşıyabilirsiniz. 
* **Sağ Tık Menüsü:** Temayı değiştirmek, Mini Mod'u açmak veya Ayarları kaydetmek için sağ tıklayın. 
* **Ayarlar:** Tercihleriniz otomatik olarak aynı klasördeki `RamOptimizer.ini` dosyasına kaydedilir.
